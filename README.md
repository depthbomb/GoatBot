# GoatBot!

GoatBot! is a general purpose Discord bot with a variety of fun, informative, and administrative commands. The bot is owned and developed by depthbomb#7698 using the Discord.js Node module.

This bot was made specifically for use in the Cyan.TF Discord server so some aspects of it are somewhat hardcoded.

---

## Installation

* Clone repo
* Run `npm install`
* Fill in config.json
* Run `npm start` to run the bot

## Adding/Disabling commands

The bot will load all commands in /core/commands/ when it boots up. All commands in the /disabled/ directory will be ignored.
