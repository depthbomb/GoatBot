# GoatBot!

GoatBot! is a general purpose Discord bot with a variety of fun, informative, and administrative commands. The bot is owned and developed by depthbomb#7698 using the Discord.js Node module.

GoatBot is a modified (and improved) version of my private Discord bot: *Koza*.

This bot was made specifically for use in the Cyan.TF Discord server so some aspects of it are somewhat hardcoded. GoatBot is also very much an unfinished product that is still being actively developed.

I generally push updates without fully testing so there might be broken things. *You have been warned.*
